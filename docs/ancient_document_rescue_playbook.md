# Public-Domain Preservation Notice

This repository may publish preservation outputs only when each item has been verified as public domain, Public Domain Mark, openly licensed for redistribution, or otherwise explicitly authorized.

Public distribution records may include only what readers need to identify and verify an object:

- preserved public-domain or redistribution-authorized files
- institutional identifier and source citation
- item-level rights statement
- version or retrieval date when relevant
- byte count and cryptographic checksum
- minimal catalogue metadata needed for discovery and integrity checking

Research methods, corpus-selection logic, acquisition adapters, recovery procedures, automation, orchestration, internal ledgers, and analytical workflows are not part of the public preservation package.

The public files are a preservation mirror, not the operational control plane. Their purpose is to keep rights-cleared historical material independently downloadable and verifiable if an original delivery endpoint later becomes unavailable.

Historical repository revisions may contain material that is no longer part of the intended public surface. Removing content from the current branch does not erase Git history.
