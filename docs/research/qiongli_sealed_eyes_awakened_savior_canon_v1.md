`上古六目羽翼神兽（未觉醒） → 看见不该看的东西 → 鱼妇期颛顼以九色线缝死六目 → 长期失目与“食目/夺目/借目”母题形成因果连续性 → UNKNOWN 条件下神格觉醒 → 六目仍缝死、羽翼枯败、兽形不改 → 反而成为救神/救世性神格。`

## 1. CURRENT TRUE HISTORY

### 1.1 上古原态
- 穷疠早期为六目羽翼神兽，六目原本全部可以开启。
- 此时穷疠**神格尚未觉醒**。
- 六目不是普通视觉器官；它们与神气、认知、灾异感知/神权接口有关。

### 1.2 禁见事件
- 穷疠曾**看见了不该看的东西**。
- 这是当前唯一锁定的直接触发层。
- 具体看见什么、为何不可见、是否主动窥视、是否涉及颛顼自身或天界秘密，全部 **UNKNOWN**。
- 禁止助手自动补完。

### 1.3 九色线封目
- 封眼者：**鱼妇形态颛顼**。
- 方式：以**九色线**将六目缝合/封死。
- 为什么不直接刺瞎/挖眼：当前只锁功能层——肉体毁眼不足以解决六目对应的神气/认知/神权接口问题；封目可以持续压制该接口。
- 详细技术机制、九色线材料与颜色分工仍 OPEN。
- 封目至少具有压制/阻止神格化的功能；颛顼当时是否明确知道未来神格结果，OPEN。

## 2. 封目 → 食目：正式因果链

后期“食目/夺目/借目”不再视为随机怪癖。

`原生六目完整 → 六目被九色线永久封缝 → 自身目权长期缺失 → 感知/能力系统围绕“目”缺口重组 → 对外部目晶/灾眼/灵目形成摄取、模拟、借权旁路`

规则：
- 吃别人的眼睛 ≠ 自己六眼真正恢复。
- 假明、借目、吞目只能形成临时/旁路能力。
- 神格觉醒以后依旧如此；六目仍被缝死。
- 原有食目六变体可继续存在，但必须服从这一更底层历史结构。

## 3. 神格觉醒：错误进化式救神

- 穷疠后来**确实神格觉醒**。
- 神格觉醒的真实触发条件 **UNKNOWN**。
- 神格觉醒 ≠ 六目解封。
- 神格觉醒以后六眼依旧被九色线缝死。
- 神格觉醒 ≠ 人形化；穷疠继续保持兽体。
- 觉醒后外观反而更加衰败：身体瘦削、病化；华丽羽翼失去羽毛，翼体干枯、残破、近似错误进化完成体，但不是完全骨骼化。
- 视觉参考只取“高阶进化却像错误进化体”的感觉，不复制具体角色设计。
- 正是在这一更丑、更残、更封闭的状态下，穷疠成为**救神/救世性神格**。

核心审美：
`外形恶化 ≠ 位格下降；肉身残缺 ≠ 神格不完整；升级 ≠ 华美。`
