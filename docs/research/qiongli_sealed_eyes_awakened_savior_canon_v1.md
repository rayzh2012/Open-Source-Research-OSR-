# 穷疠封目与神格觉醒 CANON v1.0

Status: **FICTION CANON / SOURCE-SEPARATED**

## 1. 当前锁定

- 穷疠上古早期为六目羽翼神兽；六目原本可以开启。
- 当时穷疠**尚未神格觉醒**。
- 六目后来被**缝合/封死**；封眼者为作品现行设定中的**鱼妇形态颛顼**。
- 封眼原因、地点、战役经过、直接触发条件全部 UNKNOWN。禁止自动补故事。
- 鱼妇形态颛顼可跨越较长时段存续，因此封眼事件发生在其非人长期载体阶段，而非普通人身阶段。
- 穷疠随后分别与**重体系**、**黎/祝融体系**发生冲突；两套体系都未能压制或击败穷疠。冲突原因、顺序、具体战役 OPEN。
- 穷疠后来完成**神格觉醒**，但觉醒与六眼解封没有因果关系。
- 神格觉醒后，六只眼睛依旧被缝死。
- 神格觉醒后仍保持兽形，不转成人形。
- 觉醒后的羽翼反而彻底枯败：失羽、干枯、残破，呈近乎失去正常骨羽结构的骇人异相。
- 正是在这种更残缺、更骇人的形态下，穷疠反而成为**救神/救世性神格**。这是反“升级=华美”的核心审美规则。

### TEXTUAL ANCHOR
- 《山海经·大荒西经》鱼妇—颛顼复苏链为颛顼非人长期载体提供文本锚点。
- 《国语·楚语下》“绝地天通”体系提供颛顼具有天—神—人边界治理权的古代文本锚点。
- 重、黎、祝融在传世材料中存在官职/职能与人物分合问题，可支持作品层的多体系解释。

### NOT TEXTUAL FACT
- 颛顼缝穷疠六眼。
- 穷疠与重/黎/祝融发生具体战争。
- 穷疠神格觉醒的触发机制。

以上均为作品 CANON，不可倒灌为史实。

## 4. 设计原则

`神格觉醒 ≠ 恢复完整`。

穷疠的神格觉醒应表现为：

`视觉权能仍被封死 + 外形进一步衰败 + 身体更不像“完美神兽” + 神格反而完成`。

因此穷疠的救世神形态必须保留：

- 六目缝线；
- 盲视/非视觉感知；
- 枯败无羽之翼；
- 残破、疫灾化、非人形兽体；
- 与“救神”身份形成强烈视觉反差。
