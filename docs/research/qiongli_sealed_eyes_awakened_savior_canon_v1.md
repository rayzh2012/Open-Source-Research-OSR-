# 穷疠封目与神格觉醒 CANON v1.1

Status: **FICTION CANON / SOURCE-SEPARATED**

## 1. 当前锁定

- 穷疠上古早期为六目羽翼神兽；六目原本可以开启。
- 当时穷疠**尚未神格觉醒**。
- 六目后来被**九色线缝合/封死**；封眼者为作品现行设定中的**鱼妇形态颛顼**。
- **封眼原因必须直接与穷疠六目的能力、观看行为或所见对象相关。** 这是目前唯一新增的因果约束。
- 具体看见了什么、使用了什么目力、是否看穿某种禁忌、是否造成某种后果，全部 UNKNOWN。禁止自动补故事。
- 鱼妇形态颛顼可跨越较长时段存续，因此封眼事件发生在其非人长期载体阶段，而非普通人身阶段。
- 穷疠随后分别与**重体系**、**黎/祝融体系**发生冲突；两套体系都未能压制或击败穷疠。冲突原因、顺序、具体战役 OPEN。
- 穷疠后来完成**神格觉醒**，但觉醒与六眼解封没有因果关系。
- 神格觉醒后，六只眼睛依旧被九色线缝死。
- 神格觉醒后仍保持兽形，不转成人形。
- 觉醒后的羽翼反而彻底枯败：失羽、干枯、残破，呈近乎失去正常骨羽结构的骇人异相。
- 正是在这种更残缺、更骇人的形态下，穷疠反而成为**救神/救世性神格**。这是反“升级=华美”的核心审美规则。

## 2. 封目 → 食目：当前结构

后期“穷疠食目”不再视为与封眼无关的随机怪癖，而与六目被缝建立连续结构：

`原生六目完整 → 九色线封六目 → 自身目权长期缺失 → 感知/能力系统围绕“目”这一缺口重组 → 夺目/吞目/借目成为旁路`

当前只锁 **SEALING → EYE-DEFICIT → EYE-SEEKING** 结构，不锁心理动机。

- 吃别人的眼睛 ≠ 自己六眼恢复。
- 假明、借目、吞目只能提供临时/旁路能力。
- 神格觉醒以后仍然如此；六目依旧缝死。

## 3. 古代观念锚点

《黄帝内经·灵枢·大惑论》称五藏六府精气上注于目，并有 `目者，神气之所生也`、`目者，心使也`。

这只能提供结构性文化锚点：古代思想中“目”可以承担认知、神气与精神接口意义，因此作品内的“缝目”更适合解释成**封感知/神识/权限接口**，而不是单纯毁容或普通肉刑。

这不是“颛顼缝穷疠”的历史证据。

- 《山海经·大荒西经》鱼妇—颛顼复苏链为颛顼非人长期载体提供文本锚点。

- 六目究竟因何被封。
- 穷疠与重/黎/祝融发生具体战争。
- 穷疠神格觉醒的触发机制。

以上均为作品 CANON，不可倒灌为史实。

## 6. 设计原则

`神格觉醒 ≠ 恢复完整`。

穷疠的神格觉醒应表现为：

`视觉权能仍被封死 + 外形进一步衰败 + 身体更不像“完美神兽” + 神格反而完成`。

因此穷疠的救世神形态必须保留：

- 六目九色缝线；
- 盲视/非视觉感知；
- 枯败无羽之翼；
- 残破、疫灾化、非人形兽体；
- 与“救神”身份形成强烈视觉反差。
