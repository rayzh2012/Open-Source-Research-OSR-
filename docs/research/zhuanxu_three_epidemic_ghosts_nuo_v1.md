# 颛顼三疫鬼 v1.0｜礼纬→论衡→独断/汉旧仪→搜神记 × 方相氏大傩

Status: SOURCE-CRITICAL GHOST ONTOLOGY NOTE

## Core result
汉魏晋传统里的`疫鬼`不应建模为单一物种。颛顼三子传统本身就包含三个不同异常槽位，而它们被同一岁末傩仪治理，说明`疫鬼`首先是 ritual/governance umbrella。

## Earliest recoverable Han layer
王充《论衡·订鬼》引《礼》：`颛顼氏有三子，生而亡去为疫鬼`：
- 江水：今本作`虐鬼`；
- 若水：`魍魉鬼`；
- 人宫室区隅沤库：善惊小儿。
黄晖《论衡校释》指出此`礼`为`礼纬`，并校出版本差异：江水支在《汉旧仪》作`疟鬼`，《独断》作`瘟鬼`，部分后世传本讹为`虎`。

## Liwei fragment
后世类书保存《礼纬·稽命征》残文，已把三子谱系和方相氏傩逐连接：正岁/十二月，方相氏熊皮、黄金四目、玄衣纁裳、戈盾，率百隶童子，以桃弧矢、赤丸五谷等驱疫。

## Cai Yong Dudan
《独断》：
- 江水=`瘟鬼`
- 若水=`魍魉`
- 宫室枢隅=`善惊小儿`
并接方相氏岁末大傩、桃弧棘矢、土鼓、赤丸五谷、神荼郁垒体系。

## Han Jiuyi transmission
《后汉书·礼仪志》刘昭注引《汉旧仪》保存近似三槽，并放在汉宫大傩制度中。第一槽字形/疾病名存在虐/疟/虎等传本漂移；第二槽可扩作罔两蜮鬼；第三槽仍是宫室阴湿角落惊小儿。

## Soushen Ji standardization
晋《搜神记》卷十六将三槽写得最清楚：
- 江水=`疟鬼`
- 若水=`魍魉鬼`
- 宫室=`小鬼`
并称正岁命方相氏帅傩驱疫鬼。
这不是框架的最早见证，而是后继清晰版本。
