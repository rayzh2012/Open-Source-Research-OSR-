# 颛顼封穷疠六目｜CANON closure v1.0

Status: **FICTION CANON LOCKED / TEXTUAL ANCHORS SEPARATED**

## 1. Canon conclusion

穷疠上古六目属于穷疠自身，不转移给颛顼三疫鬼。

在鸿明纪元现行设定中：

`穷疠六目开放的上古神兽期`
→ `与颛顼决裂`
→ `颛顼以生前天之帝王权限封闭六目`
→ `穷疠继续存活但高阶感知/疫灾接口被撤销`
→ `长期封印与生态退化`
→ `颛顼死亡/鱼妇重构与绝地天通时代结束其最高单人授权`
→ `穷疠神格觉醒`
→ `从神兽跃迁为真正神性存在，并形成救世神格`

## 2. Textual anchors

### 《国语·楚语下》
颛顼命南正重`司天以属神`、命黎`司地以属民`，使神民各有分序，`民神异业`，`是谓绝地天通`。

该文本只证明颛顼具有重新划分人神秩序/权限的神话政治角色；不证明他封过穷疠眼睛。

### 《礼记·月令》
`其帝颛顼，其神玄冥`。

后世礼制宇宙论明确把颛顼安置为北方/冬季帝位，为作品中的天帝权限提供文本锚。

## 3. Fiction inference

项目此前已存在匿名设定：`穷疠六目被某位天之帝王封闭`。

结合颛顼现有 CANON：
- 人间肉身尚存时已取得天之帝王权限；
- 能执行单体神兽接口封锁；
- 后来将同一治理逻辑扩大为全局`绝地天通`。

因此最省假设的闭环为：**封穷疠六目者 = 颛顼。**

## 4. Structural significance

`封穷疠六目`不是孤立事件，而是绝地天通的 prototype：

`单体高危存在权限封锁`
→ `共工战争 / 不周柱断 / 网雾暴露`
→ `颛顼鱼妇重构`
→ `Root Takeover`
→ `全局人神接口封锁（绝地天通）`

这使颛顼的政治技术演化连续，而非突然出现。

## 5. Qiongli ontology

穷疠在封目前仍是**上古神兽**，神格未觉醒。

六目封印针对的是潜在的高阶感知与疫灾接口，而不是其生命本身。颛顼没有杀穷疠，而是把它从高权限神兽降为被监管的危险存在。

神格觉醒发生在更晚阶段。觉醒后，穷疠不再只是`疫源`，而完成`疫源即疫解`的双面神格，并最终成为救世之神。

## 6. Visual canon

颛顼时代标准穷疠形象：
- 六目全部存在；
- **六目常态封闭**，由金属/骨质/神纹封线或天帝级封印纹覆盖；
- 六目不是被挖掉；
- 极端疫灾、神格震荡时可出现裂隙；
- 真正神格觉醒后，六目可重新开启，但这是系统层越权/觉醒，不是普通解封。

因此所有“上古颛顼时期穷疠”设定图若六眼全部明亮张开，应标为**觉醒后/权限突破形态**，不能作为日常封印态。

## 7. Entity split

- `QIONGLI`: 六目羽翼上古神兽 → 后神格觉醒救世神。
- `ZHUANXU_THREE_EPIDEMIC_GHOSTS`: 颛顼三子死后被礼纬/汉代傩仪归入疫鬼治理分类。

二者都与疫灾相关，但**不共享六目形态，不合并血统，不合并神格来源**。

## 8. Historical guard

现存古籍没有`颛顼封穷疠六目`直接原文；这是项目内部由既有匿名天帝封目设定与颛顼文本权限锚点闭环产生的 FICTION CANON。禁止倒灌为历史事实。
