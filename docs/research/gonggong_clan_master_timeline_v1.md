# 共工氏全时期表 v1.0｜Entity Split × 官名/氏族/政体 × 后土/四岳分支 × 鸿明 CANON

Status: **MASTER TIMELINE / SOURCE-CRITICAL + FICTION CANON SPLIT**

## 0. 总规律

`共工`不得再默认解析为一个横跨全部上古叙事的单一生物个体。

统一解析顺序：

`始祖名 / 神权名` → `氏族名` → `水政官名` → `政权/共主标签` → `不同代 Holder` → `后裔分支的新官名/新国名`。

因此任何新材料出现“共工”时，先做 Entity Split：
1. 这是 PERSON、CLAN、OFFICE 还是 POLITY？
2. 对手是谁？
3. 地理在哪里？
4. 是水政、争帝、治水失败、流放、禹伐残余，还是谱系记忆？
5. 是否能与已有 Holder 合并？若必须跨越多个传统时段，默认拆代。

## 1. 当前鸿明 CANON 输入

### GONGGONG_0｜元祖共工
- 作品层：古老水权始祖、共工号最早源头。
- 女娲 = 女娃 = 精卫本人继续 LOCK。
- 女娲为 **元祖共工之女**；这条关系优先于后世各类共工谱系。
- 用户当前设计要求：元祖共工与女娲置于同一“巴”政治/文明共同体。
- 为避免与旧“巴=蛇”假说冲突，作品层将 `巴` 处理为 **政治—文明共同体标签**，而 `Wa/蛙` 处理为 **神性/形态/水权 substrate**；二者不是同一 ontology 维度。
- 旧“共工=黑蛇族，因为相柳蛇身”继续废弃；相柳形态不得反推共工本体族属。

### 女娲双谱系问题
史料传统中 `女娃 = 炎帝之女`；项目同时锁 `女娲 = 女娃 = 精卫`、`女娲 = 元祖共工之女`。

当前不强行改成两个生物父亲，保留三种解释层：
- **CANON-A（推荐）政治/祭统再归属**：生物/始祖父系为 GONGGONG_0；后进入炎帝祭统/政治谱系，后世写成“炎帝之女”。
- CANON-B 神格—载体双阶段：同一 Wa 神格在不同政治载体阶段分别被记作共工女与炎帝女。
- TEXTUAL-C 后世谱系吸纳：炎帝系把更古老 Wa 神收入自身帝女谱系。

在未出现更强内部证据前，作品主线采用 CANON-A，避免破坏“女娲=女娃=同一主体”。

## 2. 传世文本硬锚

### A. 共工氏 = 水政/官制共同体
《左传·昭公十七年》：`共工氏以水纪，故为水师而水名`。

意义：共工首先就可以是一个以水政为组织原则的氏/官制共同体，不要求单人解释。

孔颖达《左传正义》进一步据古序列说一位共工在“大皞后、神农前”，说明古注传统本身已把“共工”放入极早时段。

### B. 共工氏曾有霸九州传统
《礼记·祭法》：`共工氏之霸九州也，其子曰后土，能平九州，故祀以为社。`

意义：共工不是只有“战败水神”形象，也存在强政治霸权/水土治理传统。

### C. 句龙是人，后土是官；“有子”可隔多代
《左传·昭公二十九年》：`共工氏有子曰句龙，为后土。`

同篇正义：`言共工有子，谓后世子耳，亦不知句龙之为后土，在于何代。`

意义：
- 句龙不必是某一共工 Holder 的直接儿子；
- 后土可理解为 `土正` 官职；
- 共工 → 句龙/后土之间允许跨数代，时间线不再被“父子”字面锁死。

### D. 《淮南子》内部已保存互相冲突的共工战争版本
- 《天文训》：共工与 **颛顼**争帝 → 触不周。
- 《原道训》：另一传统写与 **高辛**争帝 → 触不周；古注并区分其与尧时共工。

意义：至少两套政治敌手传统被“共工”同名壳承载，不宜强做单一生平。

### E. 帝喾时代另有“共工氏作乱”
《史记·楚世家》：`共工氏作乱，帝喾使重黎诛之而不尽。`

意义：颛顼战争之后/平行传统中，共工政治势力仍可继续存在；`诛之而不尽`尤其适合“氏族/政体残存”而非单人 Boss 逻辑。

### F. 尧舜时代又有一位/一职“共工”
《尚书·尧典》传统：驩兜荐共工任事，尧批评其 `静言庸违，象恭滔天`。
《舜典》：`流共工于幽州`。

意义：这是官僚/诸侯政治语境里的共工，最经济解释是后世 Holder，不必等于颛顼战争者。

### G. 《国语·周语下》明确保存“共工治水失败”与后裔反转
文本把共工的治水方式描写为壅川、堕高堙庳并最终灭亡；韦昭注还明确区分早期共工与尧时共工。

同一篇又说：`共之从孙四岳佐之`，四岳帮助禹治水。

意义：
- 共工失败并不等于整个血缘/政治网络灭绝；
- 后裔可以反过来进入新秩序；
- “共工旧水政 → 四岳协助禹的新水政”可以形成制度继承/技术路线分裂。

### H. 禹时代仍存在共工政治/军事残余
《山海经·大荒西经》有 `禹攻共工国山`；《海外北经》有 `共工之臣曰相柳氏`，并写禹杀相柳。

意义：共工可以在禹时代作为“国/残余集团/臣属网络”存在，即使某一 Holder 早已被杀、流放或失势。

### I. 《山海经·海内经》保存另一条炎帝—祝融—共工谱系
链条：
`炎帝 → 炎居 → 节并 → 戏器 → 祝融 → 共工 → 术器 / 后土 → 噎鸣`。

意义：这是明显不同于“元祖共工—女娲”以及“颛顼战争共工”的谱系壳。作品层定义为 `GONGGONG_LATE / SOUTHERN-GENEALOGICAL BRANCH`，不得倒灌成所有共工的父系。

### J. 女娲末年已有强共工氏势力是后世稳定传统
《帝王世纪》残引与《补史记三皇本纪》都保存“女娲氏末年，诸侯有共工氏，任智刑，以强伯/霸而不王”这一框架。

但这一层是较晚的历史化/神谱整编，不能用来证明西汉以前已经存在“共工撞柱导致女娲补天”的固定因果。

## 3. 共工氏 MASTER TIMELINE（作品主时间）

### PHASE -1｜元祖水权期
**实体：GONGGONG_0**
- 身份：始祖神 / 水权最高节点 / 共工号源头。
- 族属：作品层为巴政治共同体；神性 substrate 为 Wa/蛙水权系统。
- 关键关系：女娲之父。
- 时间：早于四极废与女娲补天。
- 史料状态：FICTION CANON；不是传世史料直接结论。

### PHASE 0｜女娲四极灾变与修复
**实体：NUWA / NÜWA / JINGWEI**
- 四极废、九州裂、补天、断鳌足、止淫水。
- 本次灾变 **不是** 共工撞不周山造成。
- 元祖共工体系在此时已经存在，但不作为灾难责任者。
- 女娲后切换精卫形完成海陆边界锚定。

### PHASE 1｜共工号制度化
**实体：GONGGONG_CLAN / WATER-OFFICE SYSTEM**
- 共工由始祖名扩展为氏、官、政权标签。
- `以水纪 / 水师而水名` 是这一阶段的制度记忆。
- 后续出现多个 Holder 是正常继承，而不是“同一人活太久”。

### PHASE 2｜女娲末—早期霸权共工
**实体：GONGGONG_HEGEMON_A**
- 后世《帝王世纪》传统：女娲末已经存在强大共工氏诸侯/霸权。
- 作品解释：元祖共工之后，共工氏已经从水权宗族长成区域性政体。
- **不**把“撞不周山→女娲补天”接到这里；女娲修复在前。

### PHASE 3｜霸九州—后土上游期
**实体：GONGGONG_HEGEMON_B / HOUTU-LINE UPSTREAM**
- 《祭法》记忆：共工氏霸九州，其后世子孙中出现能平九州者。
- 这里是句龙/后土分支的上游，但“其子”不作直接父子。
- 句龙具体任后土的年代仍开放。

### PHASE 4｜颛顼争帝—单柱断裂
**实体：GONGGONG_ZX**
- 与颛顼争共主/帝位。
- 战败后撞不周山，造成 **单一关键天柱/边界节点断裂**，不是女娲时代四极同时崩毁。
- 鸿明现行：柱断后出现天穹接口暴露、网雾/不明物降临风险；共工只是边界事故的触发者，不是网雾本体。
- 颛顼人身在战争中死亡/失效后，经鱼妇/半鱼载体重构，继而完成 Root Takeover 与绝地天通。

### PHASE 5｜战后吸纳：句龙/后土分支
**实体：GOULONG → HOUTU OFFICE**
- 句龙为共工后世子；`后土`为土正官职。
- 推荐作品位置：颛顼战争后至早期新秩序建立期。
- 东汉应劭引文所保存的“句龙佐颛顼”可作 **STRONG CANON OPTION**：战败共工集团的一支被新政权吸纳，改掌土地/疆理。
- 这是最适合解释“为什么敌对集团后裔反而成为后土”的政治节点。

### PHASE 6｜高辛/帝喾时代共工冲突
**实体：GONGGONG_KX**
- 《原道训》：与高辛争帝；与颛顼版本冲突。
- 《楚世家》：帝喾命重黎诛共工，且“诛之不尽”。
- 推荐：拆成颛顼战后数代的另一 Holder / 另一共工支系；其失败不消灭整个 Clan。

### PHASE 7｜尧舜官僚共工
**实体：GONGGONG_YAO**
- 政治身份更接近朝廷官/诸侯/水工负责人。
- 被推荐任事、受尧否定，舜时流于幽州。
- 古注与《国语》传统允许明确区分于更早共工。
- 作品可写为“共工号仍在中央体制内拥有水利技术与旧贵族声望，但已经从共主型政权降格为高官/边疆巨族”。

### PHASE 8｜禹治水时代：敌我两支同时存在
**实体 A：GONGGONG_REMNANT / XIANG-LIU NETWORK**
- 禹攻共工国山；相柳作为共工臣属被杀。
- 表示旧共工政治—水利集团仍有武装/地方残余。

**实体 B：SIYUE BRANCH**
- `共之从孙四岳佐之`；四岳协助禹治水。
- 同一祖系发生路线分裂：一支继续旧共工体系，一支进入禹的新水政秩序。

这是共工氏最关键的“历史转化”节点。

### PHASE 9｜禹后政治重组
**四岳 → 有吕/姜 → 许 / 齐 / 姜戎等不同政治标签**
- 共工后裔不再需要保留“共工”字面名号。
- 族群、封国、姓氏、官职可以完全重编码。
- 这为“后土政治遗产 → 后世土政体/土方”的开放模型提供机制，但尚不能直接证明商代土方就是共工后裔。

### PHASE 10｜南方炎帝谱系再编译
**实体：GONGGONG_LATE / SOUTHERN-GENEALOGICAL BRANCH**
- 《海内经》把一位共工放入 `炎帝→祝融→共工→后土` 谱系。
- 作品层：解释为南方/江水支系对共工号的重新谱系化，而不是元祖共工的真实出生记录。
- 可与巴—长江水权共同体结合，但必须与 GONGGONG_0 / GONGGONG_ZX / GONGGONG_YAO 分开。

## 4. 三套可运行 Competing Models

### MODEL A｜高分辨率多 Holder（推荐 CANON）
至少拆 6 个核心层：
1. GONGGONG_0 元祖共工；
2. GONGGONG_HEGEMON 女娲末/霸九州层；
3. GONGGONG_ZX 颛顼战争者；
4. GONGGONG_KX 高辛/帝喾冲突者；
5. GONGGONG_YAO 尧舜官僚共工；
6. GONGGONG_REMNANT 禹时代残余政体。

句龙/后土、四岳为后裔分支，不计入 Holder 数。

优点：最大程度保留所有冲突文本，不需要超长寿命，不需要强改父子年代。

### MODEL B｜四 Holder 压缩版
1. 元祖共工；
2. 女娲末—颛顼战争共工；
3. 高辛—尧舜时代共工氏政治继承者；
4. 禹时代共工残余/地方王。

优点：小说人物更少；缺点：会把《淮南子》《尚书》《国语》的不同政治语境压在一起。

### MODEL C｜极保守文本模型
不建立任何生物谱系，只建立：
- `共工氏（早期水政集团）`
- `颛顼战争传统`
- `高辛战争传统`
- `尧舜官僚传统`
- `禹伐共工传统`
- `后土/四岳后裔传统`
- `炎帝—祝融谱系传统`

这是史料审计的最低承诺版本；与作品 CANON 并行保存。
