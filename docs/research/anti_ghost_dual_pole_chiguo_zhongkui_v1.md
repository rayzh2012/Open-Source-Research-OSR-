# 反鬼双极谱系 v1.0｜尺郭生者捕食极 × 钟馗鬼化执行极

Status: SOURCE-CRITICAL + HONGMING MODEL

## Core split
- 尺郭/赤郭/天郭：活体巨大人形，核心功能是吞食恶鬼；`Human/Biological substrate → Ghost Predator`。
- 钟馗：早期文本首先保存打杀鬼的执行职能，成熟人物传记后出；鸿明模型为 `Ghost substrate + retained Human Identity → Ghost Hunter`。
- 二者功能汇流但本体、时代、传本来源独立；不得直接说同源或互为祖先。

## Chiguo textual families
### Family A: 天郭摘录支
- 668《法苑珠林》：七尺、箕头、朝吞恶鬼三千、暮三百、但吞不咋、鬼为饭、雾露为浆、天郭、食邪、黄火。
- 《太平御览》：七丈、箕头、朝三千、暮二百、但吞不咋、鬼饭、雾露浆、天郭、食耶、黄父，并保留多条解释性夹注。
- 两者共享高特异注释组合，优先解释为共享更早摘录祖型，而非完全独立 source-family。

### Family B: 尺/赤郭红衣赤蛇支
- 《太平广记》：尺郭，七丈，朱衣缟带，赤蛇绕项，朝三千暮三百，鬼食/雾浆，别名食邪、黄父。
- 《类说》：赤郭，七尺，朱衣缟带，赤蛇绕项，朝三千暮三百，鬼饭雾浆，别名食邪、黄父。
- 《说文》系统中`尺`与`赤`均见昌石切；中古均可重建至 `tsyhek` 一带。因而 `尺/赤` 可高度可信地视为同一音壳替写；具体方向仍 OPEN。红衣/赤蛇上下文为“赤”提供语义吸附。

## Tianguo is not a simple phonetic substitution
`天`与`尺/赤`不属于同一简单中古音壳；现阶段保留三种模型：
1. 独立别名；
2. 更复杂抄讹链；
3. 两支原本来自不同摘录祖型，后世再融合。

## Huangfu split
五世纪《异苑》已有独立`黄父鬼`：黄衣、形体无定、出现带疫疠，是致病鬼。
而尺郭相关传本又有`黄父/赤黄父`别名。
因此建立：
- `CHIGUO_ALIAS_HUANGFU`
- `HUANGFU_PESTILENCE_GHOST`
二者同名不等于同一实体。当前丰富《神异经》把`赤黄父`与`今世有黄父鬼`并置，可能正是后世注释吸附/合流的痕迹。

## Qitou ritualization
丰富《神异经》尺郭支有`鸡父魌头`。汉代郑玄注《周礼》明确以`魌头`说明逐疫驱鬼面具，《说文》亦云`今逐疫有魌头`。
但668《法苑珠林》最早硬钉支只有`箕头`，所以`魌头`不能倒灌为最早祖型事实。它更适合作为后层“把食鬼异人向傩/逐疫仪式人格化”的线索。

## Zhongkui early layer
《太上洞渊神咒经》相关文本保存：`钟馗打杀，得便付之辟邪`。
早期钟馗首先是反鬼执行职能，而不是完整终南进士人物传记。
成熟的玄宗梦、进士不第、吴道子画像等属于较晚 narrative shell。

## Comparative model
中国反鬼传统可能多次把器物/面具/职能人格化：
- 尺郭：食鬼异人祖型 → 后层吸收魌头/逐疫仪式视觉；
- 钟馗：終葵/椎/辟邪音壳与鬼杀职能 → 人名/神名 → 制度化反鬼执行者 → 完整传记。
这是比较模型，不是直接同源事实。

## Hongming dual pole
- 尺郭 = 生者反鬼极 / 人类怪物。
- 钟馗 = 死者或鬼化反鬼极 / 怪物英雄。
- 尺郭以鬼为食属于生态捕食；钟馗打杀/啖鬼属于同层鬼体终结与制度化执行。
- 神格边界继续保留：对鬼极强不推出可侵犯真正神格。
